Computers

Windows

Windows 10 and 11. Opens PDFs and e-books with a double click.

Download (.exe) For Windows on ARM (.exe)

Windows may say “Windows protected your PC”, because the installer is not signed with a paid certificate. Choose More info, then Run anyway.

Mac

macOS 12 and later, for Apple silicon and Intel.

Download (Apple silicon) For a Mac with an Intel processor (.dmg)

The first time, macOS will not open it with a double click: open System Settings, Privacy & Security, and choose Open Anyway.

Linux

One file that runs on most distributions (x86-64).

Download (AppImage)

Make the file executable (chmod +x), then start it.

No install

Use it in Chrome, Edge, Safari or Firefox. After the first visit it also works without a connection.

Open in the browser

In Chrome and Edge, the address bar offers to install it as an app of its own.

Phones and tablets

iPhone and iPad

  1. Open the app in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen. It opens full screen and works offline.
Open in Safari

Android

  1. Open the app in Chrome.
  2. Open the menu (three dots).
  3. Choose Install app, or Add to Home screen.
Open in Chrome

Browser extension

Chrome, Edge, Firefox

Opens every PDF link in dark mode, right in the tab. It does one thing: the dark viewer.

How to load it

It is not in the Chrome Web Store, Edge Add-ons or Firefox Add-ons yet. Until then it is loaded from the source.
