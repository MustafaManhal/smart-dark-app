## A paragraph

```
Reader343 is a PDF reader I built because every dark mode I tried turned charts into noise and photos into negatives. It flips lightness and keeps hue, so a red line stays red on a dark page. It also does highlights and notes, a notebook with Markdown and Anki export, read aloud, OCR for scans, and joining or splitting PDFs. It runs in the browser, installs on iPhone, and has desktop apps for Windows and Mac. No account, no tracking, MIT licensed.

Try it: https://smart-dark-app.vercel.app
Source: https://github.com/MustafaManhal/smart-dark-app
```
