One command sets all of it (it needs the `gh` tool, logged in as the owner):

```
gh repo edit MustafaManhal/smart-dark-app \
  --description "PDF reader with a dark mode that keeps colors and photos. Web app, desktop app and browser extension. Highlights, notes, read aloud, OCR, PDF tools. No account; everything stays on your device." \
  --homepage "https://smart-dark-app.vercel.app/about/" \
  --add-topic pdf --add-topic pdf-reader --add-topic pdf-viewer --add-topic dark-mode --add-topic pdfjs \
  --add-topic pwa --add-topic electron --add-topic browser-extension --add-topic chrome-extension \
  --add-topic firefox-addon --add-topic annotations --add-topic highlights --add-topic text-to-speech \
  --add-topic ocr --add-topic offline-first --add-topic privacy --add-topic preact --add-topic typescript \
  --add-topic arabic --add-topic rtl
```
