# Smart Dark Reader: roadmap

**Goal:** one PDF reading app, written once, shipped as a Windows/macOS desktop app (Electron) and an
iPhone web app (PWA, installed with Add to Home Screen), with Reader343-level features, our smart dark
mode, and sticky notes on the page. The existing Chrome extension keeps working.

**Rule for Reader343:** it has no license, so it is a feature checklist only. No code, icons, strings or
assets from it go into this repo.

## Architecture

```
src/                      Chrome extension (unchanged; smart-invert.js is shared)
app/                      the reader app (Vite + TypeScript + Preact)
  index.html
  public/                 icons, pdf.js assets (copied by script), fonts
  src/
    main.tsx              boot, router
    app.css               design tokens + base styles
    platform/             what differs per platform (web vs desktop bridge)
    db/                   IndexedDB: schema, migrations, repositories
    library/              import, covers, library screen
    reader/               pdf.js wrapper, page renderer, reader screen
    annotations/          bookmarks, highlights, notes, sticky notes   (plan 2)
    readaloud/            speech                                       (plan 3)
    stats/                sessions, goals, streaks, heatmap            (plan 4)
    i18n/                 English + Arabic, RTL                        (plan 5)
    settings/                                                          (plan 5)
desktop/                  Electron main + preload                      (plan 6)
test/app/                 Vitest unit tests for app/
test/app-e2e/             Playwright: Chromium (desktop) + WebKit iPhone profile
```

All user data lives in IndexedDB in both shells: the PDF bytes, covers, progress, annotations, stats and
settings. Desktop is Chromium inside Electron; iPhone is WebKit. Both get `navigator.storage.persist()`,
and the app offers a full backup export/import so nothing is lost if the iPhone web app is deleted.

## Phases (one plan each; each ends with working, tested software)

| # | Plan | Delivers |
|---|---|---|
| 1 | Foundation | tooling, design system, storage, import, library screen, reader with smart dark / sepia / light, resume, TOC, chapter progress |
| 2 | Annotations | bookmarks, multi-color highlights, passage notes, sticky notes on the page, notes review screen, backup export/import |
| 3 | Read aloud | speech with voice/speed/pitch, spoken-sentence highlight, auto next page, sleep timer, wake lock |
| 4 | Goals & stats | reading sessions, daily goal (minutes/pages), streaks, insights, activity heatmap, reminders |
| 5 | Settings, Arabic, book info | settings screen, English/Arabic with RTL, opt-in Google Books / Open Library lookup |
| 6 | Desktop app | Electron shell, file association, menus, native notifications, update check, macOS dmg (ad-hoc signed), Windows installer via GitHub Actions |
| 7 | iPhone app (PWA) | manifest, icons, offline service worker, safe areas, touch gestures, standalone polish, hosting on GitHub Pages |

Plans 2 to 7 are written in detail when the previous plan is done, because they build on its interfaces.

## Known platform limits (researched 2026-10-03)

- iPhone web apps cannot open PDFs from the Files app via "Open with"; import is through the file picker.
- iPhone reminders: no scheduled local notifications for web apps; Web Push needs a server. Plan 4 uses
  in-app reminders on iPhone and native notifications on desktop.
- iPhone read aloud must start from a tap and stops when the app goes to the background.
- macOS: without a paid Apple Developer ID, first launch needs "Open Anyway" in System Settings.
- Windows: unsigned installers show SmartScreen; the NSIS installer is built on Windows CI because
  cross-building on Apple Silicon corrupts the uninstaller (electron-builder #10258).
